Basics|What is NLP?|NLP (Natural Language Processing) teaches computers to read, understand and write human language.
Basics|Why is NLP useful?|It powers chatbots, search, spam filters, translators and voice assistants.
Basics|What is a corpus?|A corpus is a big collection of text used to train or test a model.
Basics|What is a token?|A token is a small piece of text, usually a word or part of a word.
Basics|What is tokenization?|Tokenization splits a sentence into tokens, for example "I love NLP" becomes I, love, NLP.
Basics|What is a document in NLP?|A document is one piece of text, like a review, a tweet or an SMS.
Basics|What is vocabulary?|Vocabulary is the list of all unique words found in your dataset.
Basics|What is a dataset?|A dataset is the collection of examples we use to build and check a model.
Basics|What is a model?|A model is a program that learned patterns from data and can make predictions.
Basics|What is machine learning?|Machine learning lets computers learn patterns from examples instead of fixed rules.
Cleaning|Why do we clean text?|Clean text removes noise, so the model focuses on the words that matter.
Cleaning|What is lowercasing?|It changes all letters to small letters so "Good" and "good" are the same word.
Cleaning|What are stopwords?|Stopwords are very common words like "the", "is" and "a" that carry little meaning.
Cleaning|Why remove stopwords?|Removing them keeps the important words and makes the model faster.
Cleaning|What is stemming?|Stemming cuts words to a rough root, like "running" to "run".
Cleaning|What is lemmatization?|Lemmatization changes a word to its real dictionary form, like "better" to "good".
Cleaning|Stemming or lemmatization, which is better?|Lemmatization is more accurate, but stemming is faster and simpler.
Cleaning|Why remove punctuation?|Punctuation usually adds noise in simple models, so we remove it.
Cleaning|What is text normalization?|It means making text consistent: lowercase, no extra spaces, no strange symbols.
Cleaning|What is a regular expression?|A regular expression (regex) is a pattern used to find or replace text.
Features|What is Bag of Words?|Bag of Words counts how many times each word appears, ignoring word order.
Features|What is TF?|TF (term frequency) is how often a word appears in one document.
Features|What is IDF?|IDF (inverse document frequency) gives a higher score to rare words across all documents.
Features|What is TF-IDF?|TF-IDF multiplies TF by IDF, so important and rare words get bigger scores.
Features|Why is TF-IDF better than simple counts?|It reduces the weight of common words and highlights the special words.
Features|What is a vector?|A vector is a list of numbers that represents a text.
Features|What is cosine similarity?|Cosine similarity measures how close two vectors are, from 0 (different) to 1 (same).
Features|What is an n-gram?|An n-gram is a group of n words in a row, like "machine learning" (2-gram).
Features|What is a word embedding?|An embedding is a smart vector where words with similar meaning are close together.
Features|What is Word2Vec?|Word2Vec is a method that learns word embeddings from large text.
Chatbot|What is a chatbot?|A chatbot is a program that talks with people using text or voice.
Chatbot|What is an FAQ chatbot?|It answers common questions by finding the closest stored question and returning its answer.
Chatbot|How does this chatbot work?|It turns your question into TF-IDF numbers and finds the most similar stored question.
Chatbot|What are the steps of this chatbot?|Clean the text, apply TF-IDF, compare with cosine similarity, then return the best answer.
Chatbot|What is a similarity score?|It is a number showing how well your question matches a stored question.
Chatbot|What is a confidence threshold?|It is the minimum score needed to answer, so the bot does not guess when unsure.
Chatbot|What happens when the bot is not sure?|It says it did not understand and suggests similar questions.
Chatbot|What is a rule-based chatbot?|It follows fixed rules written by a person, like if-then statements.
Chatbot|What is an AI chatbot?|It uses machine learning to understand questions instead of only fixed rules.
Chatbot|What is a retrieval chatbot?|A retrieval chatbot picks an answer from a ready list instead of writing a new one.
Sentiment|What is sentiment analysis?|It finds whether a text is positive, negative or neutral.
Sentiment|Where is sentiment analysis used?|Companies use it on reviews, tweets and feedback to see how people feel.
Sentiment|What are the sentiment labels?|Usually positive, negative and neutral.
Sentiment|What is a lexicon?|A lexicon is a dictionary of words with scores, like "good" is positive.
Sentiment|What is VADER?|VADER is a ready NLTK tool that scores the sentiment of short social media text.
Sentiment|What is polarity?|Polarity is the sentiment score, from -1 (very negative) to +1 (very positive).
Sentiment|Why is sarcasm hard?|Sarcasm says the opposite of what it means, so simple models get confused.
Sentiment|What is a movie review dataset?|It is a set of reviews labeled positive or negative, often used to train sentiment models.
Sentiment|What is negation?|Negation words like "not" flip the meaning, for example "not good".
Sentiment|What is emotion detection?|It finds feelings like joy, anger or sadness, not just positive or negative.
Classification|What is text classification?|It puts a text into a group, like spam or not spam.
Classification|What is spam detection?|It is a classification task that finds unwanted messages such as spam SMS.
Classification|What is a label?|A label is the correct answer for an example, like "spam".
Classification|What is supervised learning?|The model learns from examples that already have labels.
Classification|What is Naive Bayes?|A fast, simple classifier that uses word probabilities. It works well for text.
Classification|What is Logistic Regression?|A simple, strong classifier that gives a probability for each class.
Classification|What is SVM?|SVM (Support Vector Machine) finds the best line that separates classes.
Classification|What is a train-test split?|We split data into training (to learn) and testing (to check) parts.
Classification|What is overfitting?|Overfitting means the model memorized the training data and fails on new data.
Classification|What is a pipeline?|A pipeline chains steps, like cleaning, TF-IDF and the model, into one flow.
NER|What is Named Entity Recognition?|NER finds names of people, places, companies and dates in text.
NER|What is an entity?|An entity is a real thing in text, like "Kigali" or "Anthropic".
NER|What are common entity types?|PERSON, ORGANIZATION, LOCATION, DATE and MONEY.
NER|Give an example of NER.|In "Ann visited Kigali", Ann is a PERSON and Kigali is a LOCATION.
NER|Which tool is good for NER?|spaCy has a fast, ready NER model that is easy to use.
NER|What is spaCy?|spaCy is a Python library for fast and practical NLP.
NER|What is POS tagging?|POS tagging labels each word as a noun, verb, adjective and so on.
NER|What is a parser?|A parser finds how words in a sentence are connected (grammar).
NER|Why is NER useful?|It pulls out key facts from news, emails and documents automatically.
NER|What is entity linking?|It connects a name in text to the correct real-world item, like "Paris" the city.
Translation|What is machine translation?|It automatically translates text from one language into another.
Translation|How does modern translation work?|Neural networks learn from millions of sentence pairs in two languages.
Translation|What is a Transformer?|A Transformer is a neural network that looks at all words at once. It powers modern NLP.
Translation|What is attention?|Attention lets the model focus on the most important words when it reads.
Translation|What is Kinyarwanda?|Kinyarwanda is the national language of Rwanda, spoken by millions of people.
Translation|Why is Kinyarwanda hard for NLP?|It has little digital data and long, complex words made of many parts.
Translation|What is a low-resource language?|A language with very little text data available to train models.
Translation|What is BLEU?|BLEU is a score that compares a machine translation with a human translation.
Translation|What is multilingual NLP?|NLP that works with many languages, sometimes in one model.
Translation|Can I ask this chatbot in Kinyarwanda?|Yes, choose Kinyarwanda and speak or type. It understands key words and can translate answers.
Tools|Which Python libraries are used in NLP?|Common ones are NLTK, scikit-learn, spaCy and Hugging Face.
Tools|What is NLTK?|NLTK is a Python toolkit great for learning NLP: tokenizing, stopwords, stemming.
Tools|What is scikit-learn?|A Python library for machine learning. It has TfidfVectorizer and many classifiers.
Tools|What is Hugging Face?|A platform with thousands of ready models and datasets for NLP.
Tools|What is TfidfVectorizer?|A scikit-learn class that turns a list of texts into TF-IDF numbers.
Tools|What is Kaggle?|Kaggle is a website with free datasets and data science notebooks.
Tools|What is a Jupyter notebook?|A notebook mixes code, results and notes in one page. It is great for projects.
Tools|What is pandas?|A Python library to read and handle tables of data, like CSV files.
Tools|What is a pre-trained model?|A model already trained on big data that you can use or fine-tune.
Tools|What is fine-tuning?|Training a pre-trained model a little more on your own data.
Evaluation|What is accuracy?|Accuracy is the percentage of answers the model got right.
Evaluation|What is precision?|Of everything the model marked as positive, how much was really positive.
Evaluation|What is recall?|Of all real positives, how many the model found.
Evaluation|What is the F1 score?|F1 combines precision and recall into one balanced number.
Evaluation|What is a confusion matrix?|A table that shows correct and wrong predictions for each class.
Evaluation|How do we test this chatbot?|We ask reworded questions and check if the right answer comes back (top-1 accuracy).
Evaluation|What is top-3 accuracy?|The correct answer is inside the bot's three best matches.
Evaluation|How can I make the chatbot smarter?|Add more Q&A, add synonyms, use bigrams, or try embeddings.
Evaluation|What are the limits of TF-IDF?|It matches words, not meaning, so different words with the same meaning can be missed.
Evaluation|What is the next step after TF-IDF?|Use sentence embeddings or a Transformer to understand meaning better.
